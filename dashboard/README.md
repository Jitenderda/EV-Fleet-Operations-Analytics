# Dashboard

This folder will contain the Power BI dashboard documentation, screenshots and related dashboard files for the EV Fleet Operations Analytics project.

## Planned dashboard pages

### 1. Fleet Overview

- Total vehicles
- Active and inactive vehicles
- Fleet utilization
- Vehicle availability
- Distance travelled
- Energy consumed

### 2. Charging Operations

- Total charging sessions
- Charging success rate
- Energy delivered
- Charging cost
- Cost per kWh
- Station utilization
- Average charging duration

### 3. Battery Health

- Average state of health
- State-of-charge trends
- Battery temperature
- Charging-cycle analysis
- At-risk vehicles
- Energy efficiency by vehicle model

### 4. Maintenance

- Maintenance events
- Downtime hours
- Repair cost
- Maintenance cost per kilometre
- Fault categories
- Vehicles requiring attention

## Dashboard rules

- Every KPI must have a documented definition.
- Visuals must answer a business question.
- Filters must be tested.
- Numbers must be validated against SQL results.
- Colours and labels must be consistent.
- Charts should be simple and decision-focused.
