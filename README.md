# EV Fleet Operations Analytics

## Project status

**Status:** Planning  
**Implementation:** Not started

## Overview

A learning-led end-to-end analytics project for electric-vehicle fleet operations.

The project will analyse:

- GPS and trip performance
- Battery health
- Charging operations
- Fleet utilization
- Maintenance and downtime

## Business objective

Help an EV fleet manager understand vehicle performance, charging efficiency, battery risk and maintenance requirements.

## Planned tools

- SQL Server
- Python and pandas
- Power BI
- GitHub
- Optional: GPS, IoT and AI extensions

## Learning approach

This project will be built step by step. I will document:

- Concepts learned
- Code written independently
- Mistakes and corrections
- Data-quality decisions
- Business insights
- Project limitations

## Privacy

This project will use public, synthetic or anonymized data. No confidential company data, personal information or live GPS data will be published.
