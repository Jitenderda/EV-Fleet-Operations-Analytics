# Reports

This folder will contain written explanations of the analysis and business recommendations.

## Planned reports

```text
executive_summary.md
methodology.md
business_findings.md
limitations.md
```

## Report structure

Each final report should include:

1. Business problem
2. Data sources
3. Definitions and assumptions
4. Analysis methodology
5. Key findings
6. Business impact
7. Recommendations
8. Limitations
9. Suggested next steps

## Writing rules

- Explain findings in simple business language.
- Support important claims with numbers.
- Separate facts from assumptions.
- Do not claim causation from correlation alone.
- Clearly state limitations.
- Connect every recommendation to a finding.
- Write for a fleet or operations manager, not only for a technical audience.
