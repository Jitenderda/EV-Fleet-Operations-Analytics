This folder will contain screenshots of the Power BI dashboard and other important project outputs.

## Screenshot rules

- Use clear and readable images.
- Hide confidential information.
- Do not show personal data or live GPS locations.
- Add a short description for each screenshot.
- Use screenshots only after the underlying analysis has been validated.
