# Raw Data

This folder is reserved for original source files used in the project.

## Data policy

- Use only public, synthetic or anonymized data.
- Do not upload confidential company data.
- Do not upload personal information or live GPS data.
- Raw data files are excluded from Git using `.gitignore`.

## Planned raw sources

- Vehicle master data
- Trip and GPS summary data
- Charging-session data
- Battery-health snapshots
- Charging-station data
- Maintenance-event data

Each dataset will be documented with:

- Source
- Date collected or downloaded
- Number of rows
- Column descriptions
- Known limitations
