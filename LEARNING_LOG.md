## 11 October 2026 — Project setup

Project planning and scope definition.

### What I built

- Created the public GitHub repository
- Added the project overview
- Defined the project charter
- Created the project roadmap

### What confused me

How to include IoT, GPS, battery, charging and maintenance without making the first version too large.

### How I resolved it

Version 1 will focus on batch data analysis for data-analyst skills. Real-time IoT, AI and other advanced features will be optional extensions.
